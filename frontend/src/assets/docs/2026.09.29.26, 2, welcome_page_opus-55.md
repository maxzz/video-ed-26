**What happens now**
- **Welcome to main:** clicking "Get started" splits the Welcome page into four quarters. Each quarter flies out to its own corner (top-left, top-right, bottom-right, bottom-left) while the main page scales up from behind. At the same time the logo moves from the Welcome page into the header.
- **Main to Welcome:** clicking the logo in the header plays it in reverse. The quarters close in from the corners and the logo moves back.
- **Skipping the page:** the "Do not show the Welcome page at startup" checkbox is on the Welcome page. It saves a new `showWelcome` setting, and after a reload the app starts straight on the main page. I turned the setting back on after testing.
- **Background:** a dot-and-grid pattern over a radial gradient, light in the center and darker toward the edges. Its colors come from the theme's primary color, so it changes with the theme.

All of this uses React 19.3's transition API: `<ViewTransition>`, `startTransition` and `addTransitionType`.

**Worth knowing if you change this later**
- **No wrapper element:** the four quarters only animate if nothing wraps them inside the Welcome page. React only plays these enter/exit animations when no HTML element sits between the animated part and the page being swapped. My first version had a wrapper `div`, and the quarters silently didn't animate. `WelcomePage` now returns its content without a wrapper, and the positioned container is in `App`, which stays mounted across page switches.
- **How the split works:** each quarter is a separate, non-interactive copy of the page, clipped to one quarter. The copies appear just before the transition and are swapped back to the live page when it finishes. A 2-second fallback timer makes sure the page can't get stuck invisible.
