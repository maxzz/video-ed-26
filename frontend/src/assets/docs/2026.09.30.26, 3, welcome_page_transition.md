The "Get started" button no longer jerks when the Welcome transition ends. I checked it frame by frame in the browser before and after the change.

**Cause:** The shadcn `Button` uses `transition-all`, so it also animates `visibility`. While the four quadrant copies are on screen, the real Welcome page is hidden with the `invisible` class, and the button inherits that. When the copies are removed and `invisible` is dropped, the rest of the page shows at once. The button, though, kept animating from `hidden` and stayed invisible for one frame, so it flickered. Before the fix I measured the live button still `hidden` about 17 ms after the copies were gone. After the fix it's visible on that same frame.

**Fix:** One line in `EnterButton` in `frontend/src/components/5-welcome/1-welcome-content.tsx`. The button now animates only the properties it needs:

```tsx
<Button className="px-6 hover:bg-primary/90 transition-[color,background-color,box-shadow,translate] rounded-full shadow-md" ...>
```

The hover color, focus ring and the 1px shift on press still animate. The shared `Button` component is unchanged.

This should also help the other direction, Welcome to Main. There the old code kept the hidden button showing for about 150 ms underneath the copies as they flew apart. I only measured the Main-to-Welcome direction, so that part isn't confirmed.
